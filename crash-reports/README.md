# Отчёты GSYNK

Сюда приложение складывает отчёты, когда вы включили автоотправку
(«Инструменты → Приложение → Диагностика»).

- `crash-ГГГГММДД-ЧЧММСС.txt` — отчёт о сбое с трассировкой и журналом;
- `report-ГГГГММДД-ЧЧММСС.txt` — отчёт по кнопке.

Перед отправкой санитайзер вырезает из текста токены, почту и длинные числа.
Других данных приложение не отправляет.
