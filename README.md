# GSYNK 2.0.0 — мультитул для телефона

**GSYNK** — приложение-мультитул для Android: расписание яркости и громкости, кастомный
«остров» рядом с фронтальной камерой, NFC-связка двух телефонов, мини-игры, отложенные
задачи со звонком и озвучкой, скринсейвер, локальный чат-помощник и обновление по воздуху.

Приложение написано на Kotlin + Jetpack Compose, весь интерфейс — на русском.
Все данные хранятся только на устройстве: интернет нужен лишь для OTA-обновления.

## 1. Сборка из исходников

```bash
# нужен JDK 17 и Android SDK (platform 36, build-tools 36.0.0)
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
cd GSYNK
bash gradlew assembleDebug            # APK: app/build/outputs/apk/debug/app-debug.apk
bash gradlew testDebugUnitTest lintDebug assembleDebug   # полная проверка
```

Скрипт `check.sh` делает то же самое одной командой (в нём уже прописаны параметры
памяти для слабых машин): `bash check.sh`.

`build_toolchain.sh` — разовая установка тулчейна (JDK 17 + Android SDK + swap)
на чистой машине.

## 2. Первый запуск: доступы

Приложение не просит ничего лишнего и объясняет каждый доступ карточкой в начале экрана:

1. **Изменение системных настроек** — яркость (системная, а не «поверх окна»).
2. **Уведомления** — короткий отчёт о сработавшем правиле и ложном звонке.
3. **Постоянный остров (поверх других приложений)** — обязателен, если включён
   постоянный остров или показ капсулы при срабатывании правила.
4. **Точные будильники** — срабатывание правила в назначенную минуту, а также звонок
   и озвучка по расписанию.
5. **Не беспокоить** — переключение режима тишины (система требует отдельного доступа).
6. **Автозапуск (HyperOS)** — отдельный пункт для MIUI/HyperOS, иначе система выгружает
   приложение и будильники не срабатывают.
7. **Телефон (звонки)** — нужен только для задачи «позвонить по номеру в назначенное время».

## 3. Что умеет GSYNK

### 3.1 Расписание яркости и громкости (база приложения)

- Правила с точным временем, днями недели и **конкретными датами** (например, только
  14 и 21 октября), плюс интервалы «каждые 30 минут / 1 ч 30 мин / 3 ч».
- Разовые правила (`isOneTime`) автоматически выключаются после срабатывания.
- Яркость — системная (запись в `Settings.System`), с временным отключением
  автояркости и восстановлением прежнего режима.
- Громкость — по ступеням `STREAM_MUSIC`, честный перевод процентов в индексы.
- После перезагрузки применяется правило, чьё время было последним по графику.
- Точные будильники (`setExactAndAllowWhileIdle`), а при отказе в доступе — надёжный
  фолбэк; служба применения — `foregroundServiceType="specialUse"`.

### 3.2 Постоянный остров (кастомный Dynamic Island)

- Собственная капсула у фронтальной камеры: **работает постоянно**, пока включена.
- Показывает часы, заряд батареи и ближайшее правило; обновляется каждые 20 секунд.
- **Реагирует на нажатие**: пружинистая анимация и раскрытие дополнительной строки.
- Три положения: сверху (по умолчанию), по центру, снизу.
- Системный остров HyperOS недоступен сторонним приложениям — публичного API для него
  нет, поэтому GSYNK рисует свой (та же технология: `TYPE_APPLICATION_OVERLAY`).

### 3.3 Grape Link — связка телефонов по NFC

- **Приём**: телефон читает чужую метку или второй телефон (reader-mode) и показывает
  полученные данные; на успешное касание накладывается анимация «жидкое стекло» —
  расходящиеся цветные волны света.
- **Передача**: телефон сам становится NDEF-меткой (Host Card Emulation, Type 4 Tag) —
  `NdefHceService` обслуживает APDU-обмен, так что второй телефон читает данные
  обычными средствами.
- Передавать можно текст, ссылку и визитку; для игры есть вызов
  `плитки-tap;<модель>;<время>`.
- Честное ограничение: **NFC — канал на пару килобайт**. Текст, ссылки, визитки и
  игровые вызовы проходят мгновенно, большие файлы физически нет — для них нужен
  Wi-Fi Direct (следующий шаг развития).
- Важно: старый Android Beam (`setNdefPushMessage`) в Android 16 удалён, поэтому
  GSYNK использует HCE — это единственный актуальный способ «передачи касанием».

### 3.4 Мини-игры

- **Змейка** на плитках: чем больше съедено, тем быстрее; рекорд сохраняется.
- **Проверка реакции**: тест на время «жми на зелёное», рекорд в миллисекундах.
- **Дуэль по касанию**: игра запускается после NFC-касания, результат уходит обратно
  вторым касанием — соперник видит ваше время и полосу сравнения.

### 3.5 Tasks: звонок, фраза, розыгрыш

- «Через 3 минуты позвонить Олегу и сказать фразу» — номер, контакт, фраза и задержка
  выбираются в интерфейсе (10 с / 1 мин / 3 мин / 10 мин).
- Синтез речи (ru-RU) с ожиданием готовности движка; «Озвучить сейчас» — мгновенная проба.
- **Розыгрыш**: сначала системное уведомление «входящий звонок» (канал с высоким
  приоритетом, без кнопки «Ответить»), затем озвученная фраза — безопасная альтернатива
  пугающему настоящему звонку.
- Задачи хранятся в отдельном DataStore и удаляются после выполнения.

### 3.6 Фонарик и «Не беспокоить»

- Фонарик — через `CameraManager.setTorchMode`, состояние синхронизируется системным
  колбэком (`registerTorchCallback`; в Android 16 метода `getTorchMode` больше нет).
- «Не беспокоить» — переключение `INTERRUPTION_FILTER_PRIORITY/ALL` (нужен доступ).

### 3.7 Скринсейвер

- Логотип GSYNK летает по экрану и отскакивает от краёв, как логотип DVD: каждое
  касание стены меняет оттенок, есть пауза, ускорение и замедление.
- Размер считается по реальному размеру окна (`LocalWindowInfo`), поэтому корректен
  и в мультизадаче, и на складных экранах.

### 3.8 GrapeBot — чат-помощник

- Понимает команды текстом: «яркость 40», «громкость 0», «фонарик», «не беспокоить»,
  «включи автопилот», «сколько правил», «время», «обновление».
- Полноценная языковая модель (Gemma через MediaPipe LLM Inference) подключается
  отдельным модулем — приложение уже готово к этому (`ToolsViewModel` + `ChatMessage`).

### 3.9 Обновление по воздуху (OTA)

- Проверка релизов GitHub: приложение сравнивает свою версию с последним релизом
  репозитория (`владелец/репозиторий` указывается в интерфейсе), скачивает APK со
  страницы релиза и запускает системный установщик (`FileProvider` +
  `REQUEST_INSTALL_PACKAGES`).
- Сравнение версий понимает `v1.3`, `2.0.0-beta` и короткие записи `1.3`.

### 3.10 MAIN-режим: функции по модели телефона

- **Poco X8 Pro Max (Android 14+ с NFC) — полный набор**: все модули, включая
  постоянный остров, задачи, чат и OTA.
- **Старые телефоны (Poco X3 Pro, Android 13 / MIUI 14) — базовый набор**:
  расписание яркости и громкости, фонарик, NFC-обмен, мини-игры, скринсейвер.
- Авто-определение: Android 14+, наличие NFC и разрешение на оверлей. Режим можно
  переключить вручную в разделе «Инструменты» («Авто» / «Как на Poco X8 Pro Max» / «Базовый»).
- GRAPEUI — каркас «ОС внутри приложения» (рабочий стол, док, часы): **это заглушка**,
  логику вы дописываете сами.

## 4. Живые плитки Metro

Главный экран собран из плиток в духе Windows 8 — вместо обычных кнопок:

- плитки нажимаются с пружинистой анимацией и виброотдачей;
- «Автопилот» — живая: показывает обратный отсчёт до следующего правила;
- плитка устройства — текущий MAIN-режим;
- «Игры» — живая: показывает ваш рекорд;
- остальные плитки ведут в Grape Link, скринсейвер, инструменты и редактор правил.

## 5. Как это работает внутри

- `RuleEngine` — яркость/громкость, перевод процентов; `RuleScheduler` — расчёт
  следующего и последнего срабатывания, точные будильники, `ApplyService` — применение
  из фона; `ApplyReceiver` — приём будильника; `BootReceiver` — перезагрузка, смена
  времени и часового пояса, выдача доступа к точным будильникам.
- `IslandOverlay` — единственная реализация окна поверх других приложений (обычная и
  постоянная капсула); `IslandService` — постоянный остров (foreground service).
- `DeviceProfile` — профиль устройства и набор доступных функций; `RegionSupport` —
  проверки оверлея и доступа к «Не беспокоить».
- `NfcLink` + `NdefHceService` — обмен по NFC (чтение и эмуляция метки).
- `TaskScheduler`/`TaskRepository`/`TaskReceiver` — отложенные задачи; `AutomationActions` —
  фонарик, «Не беспокоить», звонок, синтез речи.
- `UpdateChecker` — проверка и загрузка релизов GitHub.
- `GameScores` — рекорды игр; `FakeCallNotifier` — уведомление ложного звонка.
- Хранилище — AndroidX DataStore (правила, настройки, задачи, рекорды), сериализация — kotlinx.serialization.

## 7. Что нужно знать перед установкой

- **NFC-передача работает между двумя телефонами**: один держит приём, второй —
  отдачу. Оба приложения должны быть на переднем плане, экран включён.
- **Автоматическая речь в линию** («троллинг») на части прошивок звучит только в
  динамик — это ограничение Android, а не приложения. Безобидный вариант розыгрыша —
  режим «Фейковый звонок».
- **Звонок по расписанию** требует разрешения на звонки и разрешённого автозапуска,
  иначе система выгрузит задачу.
- **Постоянный остров** без разрешения «поверх других приложений» не включается —
  приложение честно об этом скажет.
- **HyperOS** требует отдельно разрешить автозапуск и снять ограничения батареи,
  иначе будильники и постоянный остров живут недолго.
