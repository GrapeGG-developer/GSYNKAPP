# GSYNK 5.2.0 — мультитул для телефона на GIOUI Metro

**GSYNK** — приложение-мультитул для Android: расписание яркости и громкости, связь
«GSYNK рядом» с Grape Link/NFC, нагрузка на процессор, видеоускоритель и нейросеть,
полупрозрачный GIOUI с бесшовно анимированным фоном, локальная ИИ-модель с чатом прямо
на телефоне, повседневные автоматизации, прямые железные опыты и низкий уровень, 42 шифра
(до байт-кода, ASM, процессорного дампа, GS-TLS и GANONYM), категория анонимности,
мини-игры и обновление по воздуху. Интерфейс работает только в портретной ориентации,
а слева от названия стоит логотип Grape Script.

Приложение написано на Kotlin + Jetpack Compose, весь интерфейс — на русском.
Функции разложены по **категориям GIOUI**, а не лежат одной лентой; рядом — **фазы чипа**:
частоты ядер, питание изнутри, панель, радио, светодиод вспышки, мотор, датчики и память.
Все данные хранятся только на устройстве: интернет нужен лишь для проверки обновлений
(и никогда — для чата с локальной моделью).

## 1. Сборка из исходников

```bash
# нужен JDK 17 и Android SDK (platform 36, build-tools 36.0.0)
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
cd GSYNK
bash gradlew assembleDebug            # APK: app/build/outputs/apk/debug/app-debug.apk
bash gradlew testDebugUnitTest lintDebug assembleDebug   # полная проверка
```

Скрипт `check.sh` делает то же самое одной командой (в нём уже прописаны параметры
памяти для слабых машин): `bash check.sh`.

`build_toolchain.sh` — разовая установка тулчейна (JDK 17 + Android SDK + swap)
на чистой машине.

## 2. Первый запуск: доступы

Приложение не просит ничего лишнего и объясняет каждый доступ карточкой в начале экрана:

1. **Изменение системных настроек** — яркость (системная, а не «поверх окна»).
2. **Уведомления** — отчёты о правилах, обновлениях и фоновой работе.
3. **Поверх других приложений** — необязательный доступ для затемнения экрана ниже
   системного минимума и большой анимации NFC-показа у фронтальной камеры.
4. **Точные будильники** — срабатывание правила в назначенную минуту.
5. **Не беспокоить** — переключение режима тишины (система требует отдельного доступа).
6. **Автозапуск (HyperOS)** — отдельный пункт для MIUI/HyperOS, иначе система выгружает
   приложение и будильники не срабатывают.

## 3. Что умеет GSYNK

### 3.1 Расписание яркости и громкости (база приложения)

- Правила с точным временем, днями недели и **конкретными датами** (например, только
  14 и 21 октября), плюс интервалы «каждые 30 минут / 1 ч 30 мин / 3 ч».
- Разовые правила (`isOneTime`) автоматически выключаются после срабатывания.
- Яркость — системная (запись в `Settings.System`), с временным отключением
  автояркости и восстановлением прежнего режима.
- Громкость — по ступеням `STREAM_MUSIC`, честный перевод процентов в индексы.
- После перезагрузки применяется правило, чьё время было последним по графику.
- Точные будильники (`setExactAndAllowWhileIdle`), а при отказе в доступе — надёжный
  фолбэк; служба применения — `foregroundServiceType="specialUse"`.
- В 5.2 расписание — отдельное Metro-приложение из «Пуска», а рядом лежат
  **«автоматизации жизни»**: 12 готовых наборов для школы, дома/YouTube, учёбы,
  транспорта, игр, чтения, выходных, экзаменов, спорта и экономии. Набор создаёт
  обычные редактируемые правила с яркостью, громкостью и режимом «не беспокоить».

### 3.2 Пустой дом и Metro-«Пуск» 5.2

- Главный экран теперь пустой: только логотип/GSYNK и требование держать телефон
  в портретном режиме. Касание открывает отдельное меню **«Пуск»** в духе Windows 8.
- Фон «Пуск» — тёмно-фиолетовый с узором; **106 мелких плиток** разложены в 10 групп,
  названия категорий стоят над плитками, а группы листаются вправо по горизонтали.
- Новости и настройки являются отдельными плитками. Долгое нажатие закрепляет плитку
  в первую группу «моё»; широкие плитки показывают вращающиеся живые строки.
- Каждая открытая плитка — полноэкранное Metro-приложение со статус-панелью: слева
  **свернуть в активный левый угол**, дальше название, справа красная кнопка **×**.
  Закрытие возвращает в «Пуск», сворачивание — на пустой дом с активной закладкой.
- Старые промежуточные контейнеры удалены: плитка сразу открывает свою функцию, а
  выход не показывает прежние объединённые списки. Скругления GIOUI стали резкими:
  плитки 3 dp, карточки 6 dp, кнопки 4 dp.
- Островок по-прежнему полностью удалён: нет сервиса, окон, настроек и полей модели.
  Overlay-доступ оставлен только затемнению экрана и большой анимации NFC-показа.

### 3.3 Grape Link — связка телефонов

Пользовательская дверь одна: категория **«GSYNK рядом»**. Из неё открываются NFC и
Grape Link; пользовательских NFC-дверей на других плитках нет.

- **Подземелье на два телефона (2.2.1)**: NFC — знакомство, Wi-Fi — сама игра. Хозяин
  открывает комнату и показывает адрес, порт и код; гость прикладывает телефон — реквизиты
  приезжают касанием, и оба играют в одном подземелье, каждый ведёт своего героя со своего
  экрана. Мир считает телефон хозяина, гость рисует ту же комнату и отправляет только стик.
  Есть и ручной ввод адреса, и код комнаты, отсекающий чужие подключения.
- **Приём**: телефон читает чужую метку или второй телефон (reader-mode) и показывает
  полученные данные; на успешное касание накладывается анимация вспышки у фронтальной
  камеры (без цветных кругов).
- **Передача**: телефон сам становится NDEF-меткой (Host Card Emulation, Type 4 Tag) —
  `NdefHceService` обслуживает APDU-обмен, так что второй телефон читает данные
  обычными средствами.
- Передавать можно текст, ссылку, визитку, пароль, координаты, профиль GSYNK (правила
  расписания) и вызов в игру; вызов теперь несёт ещё адрес комнаты, порт и код.
- Честное ограничение: **NFC — канал на пару килобайт**. Текст, ссылки, визитки и
  реквизиты игры проходят мгновенно, большие файлы физически нет — для них есть Wi-Fi.
- Важно: старый Android Beam (`setNdefPushMessage`) в Android 16 удалён, поэтому
  GSYNK использует HCE — это единственный актуальный способ «передачи касанием».

### 3.4 Игры

- **Подземелье GSYNK** — рогалик сверху вниз в духе The Binding of Isaac: комнаты, камни,
  враги трёх видов, босс на этаже, слёзы вместо пуль, предметы, этажи и счёт. Поле живёт
  в полосе фронтальной камеры, управление — квадратные стики под большими пальцами.
  Режимы: один игрок и **вдвоём на двух телефонах по Wi-Fi** — каждый игрок на своём экране.
- **Мини-игры**: «Реакция», «Память» и «2048» — с рекордами на телефоне.

### 3.5 Нагрузка: процессор, видеоускоритель, нейросеть

- Прямая плитка нагрузки из «Пуска» нагружает телефон по-настоящему: все ядра считают
  матрицы во float, видеоускоритель рисует поле шейдером (Android 13+), а нейросеть
  8 → 24 → 16 → 3 работает одновременно и дообучается на ходу.
- Показываются честные цифры: миллиарды операций в секунду, кадры ускорителя, температура
  батареи, ошибка обучения; при 45 °C нагрузка глушится сама.
- Фон приложения бесшовно переливается всегда; нагрузка меняет акцент и интенсивность засветок.

### 3.6 Фонарик и «Не беспокоить»

- Фонарик — через `CameraManager.setTorchMode`, состояние синхронизируется системным
  колбэком (`registerTorchCallback`; в Android 16 метода `getTorchMode` больше нет).
- «Не беспокоить» — переключение `INTERRUPTION_FILTER_PRIORITY/ALL` (нужен доступ).

### 3.7 Скринсейвер

- Логотип GSYNK летает по экрану и отскакивает от краёв, как логотип DVD: каждое
  касание стены меняет оттенок, есть пауза, ускорение и замедление.
- Размер считается по реальному размеру окна (`LocalWindowInfo`), поэтому корректен
  и в мультизадаче, и на складных экранах.

### 3.8 GrapeBot — чат-помощник

- Понимает команды текстом: «яркость 40», «громкость 0», «фонарик», «не беспокоить»,
  «включи автопилот», «сколько правил», «время», «обновление».
- Полноценная языковая модель (Gemma через MediaPipe LLM Inference) подключается
  отдельным модулем — приложение уже готово к этому (`QuickActionsViewModel` + `ChatMessage`).

### 3.9 Обновление по воздуху (OTA)

- Проверка релизов GitHub: приложение сравнивает свою версию с последним релизом
  репозитория (по умолчанию уже указан `GrapeGG-developer/GSYNKAPP`), скачивает APK
  со страницы релиза и запускает системный установщик (`FileProvider` +
  `REQUEST_INSTALL_PACKAGES`).
- **Правила после перезагрузки**: будильники Android не выживают ребут, поэтому при
  включении телефона расписание ставится заново, а состояние приводится к последнему
  уже наступившему правилу.
- **Как проверить обновление своими руками**: установите сборку предыдущей версии,
  откройте в «Пуске» плитку «обновление», нажмите «Проверить обновление» —
  приложение увидит свежий релиз, скачает его и предложит установку.
- Сравнение версий понимает `v1.3`, `2.0.0-beta` и короткие записи `1.3`.

### 3.10 MAIN-режим: функции по модели телефона

- **Poco X8 Pro Max (Android 14+ с NFC) — полный набор**: все модули, включая
  шифры, анонимность, железные опыты, чат и OTA.
- **Старые телефоны (Poco X3 Pro, Android 13 / MIUI 14) — базовый набор**:
  расписание яркости и громкости, фонарик, NFC-обмен, мини-игры, скринсейвер.
- Авто-определение: Android 14+, наличие NFC и разрешение на оверлей. Режим можно
  переключить вручную в отдельной плитке настроек («Авто» / «Как на Poco X8 Pro Max» / «Базовый»).
- GRAPEUI — каркас «ОС внутри приложения» (рабочий стол, док, часы): **это заглушка**,
  логику вы дописываете сами.

### 3.11 Шифраторы, машинный уровень и анонимность

- **42 обратимых преобразования** в одном окне и с автоопределением: Base64, Base32,
  Base58, Ascii85, Quoted-Printable, ROT13, Атбаш, Виженер, цифры 6/7 и 4/2 (главные
  6 и 4 — единицы; старые сообщения читаются fallback-ом), G/S, натуральные цифры,
  лица, виноград/банан, поросячий код **🐽 = 0, 🐷 = 1**, коты, луны, шахматные круги,
  Брайль, руны, ДНК, десятичные/восьмеричные/троичные/четверичные байты и римские числа.
- **Умная расшифровка** снимает до 16 слоёв подряд: если один и тот же шифр применили
  несколько раз, GSYNK идёт по цепочке до исходного текста и показывает её названия.
- **Машинные виды**: байт-код `0xNN`, ассемблер `mov …, 0xNN; call emit_byte` и
  процессорный дамп `MEM` с IP/SP. Это обратимые текстовые представления UTF-8, а не
  запуск чужого кода.
- **GS-TLS уровня HTTPS** — честный ECIES-пакет: пара P-256 у получателя, новый
  эфемерный ECDH для каждого сообщения, HKDF-SHA256 и AES-256-GCM. GSYNK не становится
  HTTPS-сервером; тот же класс криптографии упакован в текст `GSTLS1.…`.
- **GANONYM** — компактный пакет `GA1.…`: raw Deflate, случайная добивка размера до
  ступеней, PBKDF2-HmacSHA256 (240 000 кругов) и AES-256-GCM. В пакете нет автора,
  адресата, времени, устройства или других метаданных человека.
- Категория **«анонимность»**: персона и ники из текстового зерна, конструктор
  нейтральных аватарок 8×8 с сохранением PNG в `Pictures/GSYNK`, локальная проверка
  почты, телефонов, ссылок и повторяющегося стиля текста.
- Плитка **«низкий уровень»**: HEX/бинарные дампы, BE/LE, XOR/SUM/CRC32/Adler32,
  MD5/SHA-1/SHA-256 и трассировка учебного CPU с IP, A/B/C и флагами C/Z.
- Отдельная плитка **«новости 5.2»** показывает каждый пункт релиза иллюстрированной
  карточкой; пустой домашний экран новостями не засоряется.

## 4. Живые плитки GIOUI Metro

«Пуск» собран как горизонтальная лента групп Windows 8:

- категории подписаны над своими наборами, плитки мелкие и почти острые;
- «GSYNK рядом» показывает NFC/Grape Link/Bluetooth/Wi-Fi Direct и счётчик касаний;
- расписание и автоматизации показывают активные правила и ближайшее изменение;
- шифры, анонимность, новости, диагностика, агент и обновление отображают реальное состояние;
- долгое нажатие добавляет функцию в первую группу «моё»;
- свёрнутая функция помечается в «Пуске» и ждёт на пустом доме в активном левом углу.

## 5. Как это работает внутри

- `RuleEngine` — яркость/громкость, перевод процентов; `RuleScheduler` — расчёт
  следующего и последнего срабатывания, точные будильники, `ApplyService` — применение
  из фона; `ApplyReceiver` — приём будильника; `BootReceiver` — перезагрузка, смена
  времени и часового пояса, выдача доступа к точным будильникам.
- `Ciphers` — все 42 шифра, криптопакеты и многослойный `decodeLayers`; `Anonymity` — персоны, ники, аватарки и следы;
  `LowLevel` — дампы/endian/хэши/CPU-трасса; `ReleaseNews` — пункты встроенных новостей.
- `StartScreen` — пустой дом, горизонтальный «Пуск» и `MetroAppShell`; `FeatureHost`
  напрямую запускает tool/flag/lab-маршруты без хабов. `LifeAutomations` содержит
  детерминированные готовые правила, а `ScheduleScreen` — ручной редактор расписания.
- `DeviceProfile` — профиль устройства и набор доступных функций; `RegionSupport` —
  проверки оверлея и доступа к «Не беспокоить».
- `NfcLink` + `NdefHceService` — обмен по NFC (чтение и эмуляция метки).
- `DeviceLab` — данные прямых железных плиток (ИК-коды NEC, катушки, датчики);
  `ScreenDimmer` — затемнение ниже системного минимума; `NfcShow` — показ по касанию;
  `FileLink` — передача файлов по касанию с докачкой по Wi-Fi; `NfcTagWriter` — запись меток;
  `CommandBot` — помощник на командах вместо языковой модели.
- `WifiCoop` — подземелье на два телефона: TCP-сокеты, комната, код сопряжения и обмен
  кадрами; `CoopCodec` — текстовый кодек кадра и ввода (дроби целыми, кириллица в base64).
- `AutomationActions` — фонарик, «Не беспокоить», сирена, вибрация и системные экраны.
- `UpdateChecker` — проверка и загрузка релизов GitHub.
- `GameScores` — рекорды игр; `RogueGame` — движок подземелья (чистые данные, покрыт тестами).
- Хранилище — AndroidX DataStore (правила, настройки, рекорды), сериализация — kotlinx.serialization.

## 7. Что нужно знать перед установкой

- **NFC-передача работает между двумя телефонами**: один держит приём, второй —
  отдачу. Оба приложения должны быть на переднем плане, экран включён.
- **Слой поверх приложений** нужен только затемнению экрана и NFC-показу; без него
  остальные функции продолжают работать.
- **HyperOS** требует отдельно разрешить автозапуск и снять ограничения батареи,
  иначе точные будильники живут недолго.
