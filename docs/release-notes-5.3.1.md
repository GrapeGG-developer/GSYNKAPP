# GSYNK 5.3.1 — «плитки на весь экран, без поиска» (versionCode 25)

## Главное

- Из «Пуска» полностью удалён поиск: поле ввода, callback и состояние запроса.
- Поле плиток теперь занимает всю доступную высоту альбомного экрана после компактной 48-dp шапки.
- Размер ячейки считается от реальной высоты области плиток. Цель — 88 dp и выше, верхний предел — 132 dp; прежний предел 62 dp убран.
- Категории по-прежнему подписаны над группами, а сами группы листаются вправо.

## Что сохранено из 5.3.0

- Веб-версии GSYNK нет: сайт проекта остаётся страницей загрузки последней Android-версии.
- Сторож обновлений просыпается каждые 200 мс и следит за сроком сетевой проверки.
- Найденный APK скачивается автоматически, сверяется по SHA-256 и открывается в системном установщике Android.
- После успешной установки новая версия удаляет временный `gsynk-update.apk` и устаревшие `.part`, чтобы кэш не засорялся.
