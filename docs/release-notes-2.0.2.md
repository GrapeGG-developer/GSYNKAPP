# GSYNK 2.0.2

Обновление надёжности: задачи больше не теряются после перезагрузки и обновления приложения.

## Исправлено

- **Задачи (звонок, озвучка, розыгрыш) восстанавливаются после перезагрузки телефона.**
  Будильники в Android не выживают ребут, поэтому при включении телефона GSYNK сам
  заново ставит актуальные задачи в расписание, а просроченные убирает из списка.
- **То же самое при обновлении приложения** — включая обновление по воздуху:
  задачи, поставленные до обновления, продолжают работать после него.
- **Постоянный остров** больше не рисует полосу прогресса срабатывания — она нужна
  только временной капсуле, а у постоянной выглядела как пустая полоска.

## Добавлено

- **Подсказка про разрешение на звонки** в разделе «Инструменты → Отложенные задачи»:
  если разрешение не выдано, GSYNK честно говорит, что задача откроет набор номера,
  и предлагает выдать доступ одним нажатием.
- Три новых теста на восстановление задач (итого **41**).

## Внутри

- Логика восстановления вынесена в `TaskScheduler.restore()` — чистую функцию без
  обращения к Android, поэтому она покрыта юнит-тестами.

## Проверки

- Тесты: 41/41. Lint: 0 ошибок. Сборка: успешно.
