# GSYNK 3.0

Крупное обновление. Починены все жалобы из отчёта с телефона, добавлены связь по
Bluetooth и Wi-Fi Direct, музыка из частот, передача обновления по NFC и полная
кастомизация интерфейса.

## Починено (всё — из ваших отчётов)

| Что было | Причина | Что сделано |
|---|---|---|
| Кнопки «Нагрузка» и «Хроника» не нажимались | у панели не было `return`: список инструментов рисовался **поверх** и перехватывал нажатия | `return` добавлен, сторож `UiGuardTest` следит за всеми панелями |
| Вибромотор молчал | HyperOS глушит вибрацию без явного назначения | новый `Haptics`: играет как «сигнал» (USAGE_ALARM), есть запасные дорожки и проверка API |
| Интерфейс заезжал под строку состояния, кнопки было не нажать | полноэкранная панель разрешений не учитывала вырез и панель навигации | `windowInsetsPadding(safeDrawing)` + сторож `UiGuardTest` |
| Обновления проверялись редко | проверка раз в 20 минут, при возвращении — с задержкой 15 минут | теперь **каждые 2 минуты** и на каждом возвращении в приложение (лимит GitHub — 60 запросов в час, 30 безопасны) |
| Разделы «Скрытое Android» и «HyperOS» ничего не открывали | в отчёте всё `false`: на Android 16 и HyperOS эти экраны закрыты для сторонних приложений | оба раздела удалены целиком вместе со списками; вместо них — «Композитор» и «Камертон» |

## Новая связь: «GSYNK рядом»

Второй канал связи с другим человеком, которому нужен GSYNK — без NFC и без роутера.

- **Bluetooth**: поиск устройств (сопряжённые сверху), приём гостя, рукопожатие своим
  UUID службы `GSYNK`. По каналу уходят: показ сцен, сообщение, сценарий целиком,
  обновление, короткий файл (до ~600 байт прямо в строке).
- **Wi-Fi Direct**: телефоны сами создают сеть; по ней — игра GTBOI и файлы
  (те же порты, что у Grape Link: 45 991 и 45 992).
- **Передача игры**: хозяин нажимает «Я хозяин» — гостю уходит адрес сети, и он
  заходит в бой одним нажатием.
- Журнал связи: видно каждое действие и каждую ошибку; всё дублируется в отчёты.

## Обновление по NFC (главная фича 3.0)

APK на 35 МБ в метку не влезает, и по NFC его не передать физически. Поэтому касание
передаёт **описание релиза**:

- версия, прямая ссылка на APK и контрольная сумма уезжают в одной NDEF-записи
  (умещается в метку на 492 байта);
- второй телефон показывает карточку «Обновление передано вам» с кнопками
  **«Проверить обновление»** и **«Скачать APK»** — скачает сам, по своей сети;
- есть и **сигнал** «проверь обновление» — одна цифра с именем отправителя: друг
  касается телефона, и GSYNK сразу идёт проверять версию;
- всё это работает и по Bluetooth, и по Wi-Fi Direct, и по NFC — канал любой.

## Музыка из частот

- **Кнопка удержания** (в «Катушках» и в «Камертоне»): пока палец на кнопке — идёт
  ровный тон, ведёте палец — частота едет без разрывов (живой `AudioTrack`, а не
  перезапуск звука).
- **«В мотив»**: понравившиеся частоты складываются в список, и из них играется мотив.
- **Композитор**: 12 клавиш (мажор, минор, пентатоника, целотон), запись нот, транспон
  и темп, 5 готовых мотивов, свои мотивы с именами (до 40), отправка другу по связи,
  копирование мотива в буфер.

## Кастомизация

- 5 акцентов (виноград, лёд, янтарь, изумруд, гранат) — меняются заголовки и фон;
- скорость переливания фона: спокойно / обычно / быстро;
- размер плиток: мелкие / обычные / крупные;
- вибрация на нажатия, щелчок при нажатии, счётчики на плитках, плотный список.

## Прочее

- В «Диагностике» — **проверка железа**: вибро, звук и состояние мотора (умеет ли
  менять силу).
- Датчики: подписка только на публичные (фикс вылета AON из 2.3.0 остаётся).
- Разрешения: добавлены «Рядом с устройствами» (Bluetooth) и «Рядом с Wi-Fi»;
  они необязательные — без них работают всё остальное.
