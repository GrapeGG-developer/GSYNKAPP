# GSUI V4 / V4p1 — итог

Версия 4.0.1 (versionCode 16). Здесь — что вошло в релизы и чем это проверено.
Подробные тексты: `docs/release-notes-4.0.md` (V4) и `docs/release-notes-4.0.1.md` (V4p1).

## V4p1 — патч по делу

Человек сказал прямо: «в функциях запутался, интерфейс не изменился, а лаборатория — это
скудные датчики вместо управления железом». Патч отвечает ровно на это.

- **Папки вместо фильтров** (`ui/V4P1Screens.kt` → `FolderHubScreen`, `FolderStrip`):
  лента папок на главном со счётчиками, вход внутрь без «под-под-подпунктов», поиск и
  сортировка на экране «Папки», «мои» и «недавние» собираются сами. Тесты следят, что
  у каждой плитки есть папка и в каждой папке что-то лежит.
- **Фазы чипа** (`core/ChipLab.kt` + 8 экранов): частоты ядер и режимы, питание изнутри
  (ток/ватты/износ), панель и наклон, радио-тракт, светодиод вспышки со ступенями яркости
  и своим стробоскопом, мотор (резонанс, добротность, магнитное эхо), датчики изнутри
  (включая закрытые системой), память и планировщик. Запись в `/sys` — только с root,
  только по нажатию, с ответом системы. Правило: не врём, где система закрыта.
- **Вау-эффекты**: `AuroraField` (живое сияние, теперь на каждом экране через `GrapeScreen`),
  `ParallaxBox` (смещение от наклона через акселерометр), блик по плитке, новый «герой».
  Работают только при уровне эффектов LIGHT/FULL.
- **Стиль до конца**: все 27 файлов интерфейса на `Metro.Type`; больше нет смеси «новое/старое».
- **Проверки**: `bash check.sh` — BUILD SUCCESSFUL, тесты **229/229**, lint 0.
  Новый `V4P1Test` покрывает hex-разбор, износ батареи, единицы, вердикт по режиму,
  рисунок точек мотора, экраны фаз и целостность папок.

## Что сделано

**1. NFC — починен полностью**

- Корень «нет поддерживаемых приложений для метки»: в манифесте был один MIME-тип.
  Теперь 4 MIME + `text/plain` + схема `gsynk` + `TECH_DISCOVERED` и
  `res/xml/nfc_tech_filter.xml` (9 технологий).
- Сообщение метки — три записи (человеческая, полная, AAR), разбор предпочитает простые.
- Анимация не врёт: единственный источник событий — `core/NfcPulse.kt`
  (`readerCame`, `tagFound`, `written`); «подключено» рисуется только по настоящему касанию.
- После коннекта есть чем заняться: показать сцену, передать сценарий, сообщение, файл,
  обновление, сигнал «проверь обновление».

**2. Отчёты — без ввода руками**

`core/Keys.kt`: токен (4 части + `by lazy`) и репозиторий вшиты; санитайзер вырезает секреты.

**3. «Нагрузка» = стенд + честная нагрузка**

`core/Bench.kt`, `ui/BenchScreen.kt`: 7 этапов, открытая формула балла, класс устройства,
сравнение прогонов и с телефоном друга, история 12 прогонов, передача результата текстом.
Нагрузка на телефон — разогрев всех ядер с автостопом по 45 °C.

**4. Островок 2.0**

Посадка по вырезу камеры (`cutoutPx`), максимальное скругление, живое стекло, настройка
`islandHugCamera` и сдвиг, показ прогресса скачивания в реальном времени
(`showPersistent` / `updatePersistent`), финал «скачано, ставлю», капсула для новой версии.

**5. Обновления сами**

Круг автопроверки 2 минуты, при возвращении — 90 секунд, отметка несвежих данных,
скачивание и установка из островка. Лимит GitHub не задевается (30 запросов в час из 60).

**6. Metro (Windows 8.x)**

`ui/Metro.kt` по исходникам Microsoft: сетка 20 px, зазоры в один юнит, размеры
1×1 / 2×2 / 4×2, палитра Windows Phone 8 и Windows 8, типографика Segoe UI
(42 pt Light — заголовок, 20 pt Light — подзаголовок, 15/13/11 — текст и подписи),
раскладка `MetroGrid` без наложений. Все экраны переведены на `Metro.Type` и skin-скругления,
включая `SettingsSheet`, `UpdateSheet`, `DiagnosticsScreen`, `NearbyScreen`, `NfcLinkScreen`,
`ChronicleScreen`, `TurboScreen`.

**7. Плитки, каталог, сортировка**

Плитки Windows Phone 8–10: квадратные, живые, трёх размеров, без под-под-подпунктов.
`ui/Catalog.kt` — 66 плиток, 7 категорий, 6 сортировок (часто, а-я, недавние, категории,
мои, новое), поиск, избранное долгим нажатием.

**8. Эффекты**

`ui/Effects.kt`: матовое, жидкое, морозное и аква-стекло, живое размытие (Android 12+),
лучи, трассировка тени, зерно, фокус-кольцо, «вуаль», сетка; уровни полные / облегчённые /
простые — по профилю железа.

**9. Лаборатория железа**

25 экранов и 24 дополнения: ШИМ-микроскоп, мерцание камерой, компас, барометр и высота,
гироскоп-уровень, запись акселерографа, приближение, люксметр, заряд/ток/напряжение,
термощуп по зонам, осциллограф, спектр, свип-генератор, ультразвук, мультитач, магнитный
след, BLE-карта, каналы и сила Wi-Fi, USB/OTG, задержка экрана, вибро-код, ядра, память,
ускоритель. Везде — `DeviceLab.SAFETY_NOTE`: загрузчик, прошивку и разделы не трогаем.

**10. Ежедневное и пасхалки**

`core/Daily.kt` + `ui/Gsui4Screens.kt`: набор дня из даты (факт, задание, прикол, число дня,
цвет дня), серия посещений, подарки на 3/7/14/30 дней, рулетка «случайная функция»,
22 пасхалки — каждая за реальное действие, за находки открывается секретный набор кожи.

**11. ИИ по-настоящему**

`core/AiNet.kt`, `ui/AiScreen.kt`: офлайн-помощник, OpenAI, Groq, OpenRouter, Ollama,
свой адрес; адрес, модель, ключ, температура, длина ответа; проверка соединения.
