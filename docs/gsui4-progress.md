# GSUI V4 — что уже сделано и что осталось

Версия в разработке. Нумерация интерфейса — GSUI V4 (ориентир vc15, релиз 4.0).

## Готово и проверено

- **NFC починен полностью.** Корень «нет поддерживаемых приложений для метки» — один
  MIME-тип в манифесте. Теперь: 4 MIME + `text/plain` + схема `gsynk` +
  `TECH_DISCOVERED` и `res/xml/nfc_tech_filter.xml` (9 технологий). Сообщение метки —
  три записи (человеческая, полная, AAR), разбор предпочитает нетехнические записи.
- **Анимация больше не врёт.** Единственный источник событий — `core/NfcPulse.kt`:
  `readerCame` (HCE получил `READ_BINARY`), `tagFound`, `written`. Кнопка «пример»
  статусом подключения не считается.
- **Токен и репозиторий вшиты** (`core/Keys.kt`, 4 части + `by lazy`), ввод руками не нужен.
- **«Нагрузка» = аналог AnTuTu** (`core/Bench.kt`, `ui/BenchScreen.kt`): 7 этапов, баллы,
  класс устройства, сравнение, отправка другу, история. Маршрут: плитка «бенчмарк»,
  мультитул → «Нагрузка», роутер `page:bench`.
- **Бенчмарк и лаборатория в маршрутах**: `Router` (в `ui/Catalog.kt`) умеет `panel:`,
  `page:`, `tool:`, `flag:`, `lab:`, `sys:`.
- **Metro-фундамент по исходникам Microsoft** (`ui/Metro.kt`): сетка 20 px, зазоры в
  один юнит, размеры 1×1 / 2×2 / 4×2 / 4×4, палитра Windows Phone 8, типографика
  Light 42/20/15/13/11. Своя раскладка `MetroGrid` без наложений.
- **Эффекты** (`ui/Effects.kt`): матовое, жидкое, морозное и аква-стекло, живое
  размытие, лучи и трассировка тени, растр 20 px, «фокус», дыхание фона. Уровни
  эффектов: полные / облегчённые / простые — по профилю железа.
- **Скругления точечно** (`core/Skin.kt`): плитки прямые, карточки, кнопки,
  переключатели, листы, остров — у каждого своё значение; пресеты «metro чистое»,
  «стеклянное», «морозное», «аква», «облегчённое», «квадратное».
- **Остров 2.0**: посадка по вырезу камеры (`cutoutPx`, а не строка состояния),
  максимальное скругление капсулы, живое стекло (два оттенка перетекают в реальном
  времени), настройка посадки `islandHugCamera`, сдвиг до −60…+120 точек.
- **Каталог всего приложения** (`ui/Catalog.kt`): 70+ плиток, семь категорий, шесть
  режимов сортировки, поиск, избранное долгим нажатием, поиск по подписям. Ни одного
  под-под-подпункта.
- **«Каждый день»** (`core/Daily.kt`, `ui/Gsui4Screens.kt`): набор дня считается из даты
  (детерминированно), серия дней, подарок, задание; 15 пасхалок с наградами, разблокировка
  действиями, а не настройками (например, семь касаний значка).
- **Настоящие ИИ-сети** (`core/AiNet.kt`, `ui/AiScreen.kt`): OpenAI-совместимый протокол,
  OpenAI, Groq, OpenRouter, домашняя Ollama, свой адрес; ключ только в настройках
  телефона; офлайн-помощник как основа.
- **Лаборатория железа расширена на 24 экрана** (`core/Deep.kt`, `ui/DeviceLabA.kt`,
  `ui/DeviceLabB.kt`): частоты ядер и регуляторы, тепловые зоны, ток и мощность зарядки,
  ускоритель через EGL, память и диск, все датчики с характеристиками, акселерограф,
  компас, барометр, приближение, люксметр, шаги, латентность экрана (метрики кадров),
  мультитач, замер мерцания камерой (`core/Flicker.kt`) плюс стробоскопическое сравнение,
  осциллограф, спектр (алгоритм Гёрцеля), свип-тон, вибро-орган, BLE-радар, каналы и
  сигнал Wi-Fi, USB/OTG, визитка на метку.
- **Автообновление**: проверка сама (2 минуты / при возврате), новая версия приходит
  фирменной капсулой в островке, панель открывается автоматически.
- **Проверки**: `bash check.sh` — BUILD SUCCESSFUL, тесты **163/163**, lint **0 ошибок**.

## Осталось до релиза 4.0

1. Metro-облик остальных экранов: `SettingsSheet`, `UpdateSheet`, `DiagnosticsScreen`,
   `NearbyScreen`, `NfcLinkScreen`, `ChronicleScreen`, `TurboScreen` — перевести на
   `MetroHeader` / `MetroGroup` / `Tile8`, не теряя функции и вид.
2. Экран обновлений целиком автоматическим: пульс прогресса в островке, «качаю / ставлю».
3. Ещё «приколы» и ежедневные мелочи (по желанию пользователя их больше = лучше).
4. Полировка: единый ритм отступов, проверка прокрутки на 1280×2772, тесты на новый UI.
5. Нумерация: vc15 / `versionName = "4.0"`, доки (`CHANGELOG`, `README`,
   `docs/release-notes-4.0.md`), сборка APK, релиз на GitHub, чистка workspace.
