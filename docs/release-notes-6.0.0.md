# GSYNK 6.0.0 EXP — GSYNK Script UI

**versionCode:** 38 · **versionName:** 6.0.0 · **статус:** постоянная дизайн-система GSYNK

## Главное

Зафиксирована собственная постоянная система **GSYNK Script UI**. Это не копия чужих оболочек и не очередной скин: дальнейшие версии будут только дорабатывать эту систему, не меняя парадигму навигации.

- **Script:** типографика, нумерованные строки, подписанные главы, активная строка, собственные геометрические глифы и живые статусы.
- **Monolith:** неизменный каркас экрана — состояние сверху, глава, активная строка, строки функций, контекстные действия снизу. Категории меняют содержимое «грани», а не структуру экрана.
- **Современность:** чистые отступы, Inter, крупные номера строк, понятная иерархия, спокойные 2D-анимации.

## Визуальный язык

- Плоские **2D-градиенты** и чёткая непрозрачная палитра: ink, surface, violet, cyan, amber, success, danger, text, muted.
- **Без стекла:** нет полупрозрачных GSYNKPRG-панелей, бликов-полос, матового стекла и размытия.
- **Без 3D-перспективы:** нет `cameraDistance`, `rotationX/Y`, `shadowElevation`, AGSL-авроры и рулонных окон.
- **Изометричные скругления:** асимметричные радиусы `RoundedCornerShape` с диагональным акцентом на карточках, кнопках, чипах и панелях.
- Никаких серых линий, кассетных кругов, перфорации и катушек.

## Навигация и управление

- Один общий `awaitEachGesture`-детектор: непрерывная фаза строк, инерция и пружинное доведение `Animatable`.
- Главы переключаются дискретно жестом ←/→ или кнопками; структура экрана остаётся неизменной.
- Крупные экранные кнопки **← / → / ↑ / ↓ / ★ / OK**.
- Касание соседней строки плавно наводит фокус; касание фокуса или OK открывает приложение; ★ закрепляет функцию.
- `AnimatedContent` для смены главы и активной строки — только fade, без 3D.

## Архитектура

- `core/Script.kt`: версия системы, палитра, непрерывная фаза, циклические расстояния, инерция, 2D-трансформы строк, изометричные радиусы.
- `ui/ScriptDesign.kt`: `ScriptBackground`, `ScriptSurface`, `ScriptFocusBar`, `ScriptControlButton`, `ScriptIcon`, `ScriptGlyph`, `ScriptTexture`, `ScriptEdgeMark`, `ScriptCorners`, `ScriptInfiniteOrbit`, `ScriptDepthBackdrop`, `ScriptShards`.
- `ui/ScriptStartScreen.kt`: Monolith-каркас, главы, активная строка, нумерованные строки, жесты и кнопки.
- `ui/ScriptSettingsScreen.kt`: единые настройки Script UI.
- Общие `Components.kt`, `GrapeScreen`, кнопки, чипы, заголовки и разделители переведены на Script UI.
- Прежние GREAL-компоненты оставлены как плоские совместимые обёртки, чтобы не ломать внутренние экраны; визуально они больше не дают стекла и 3D.
- Устаревшие Blade-файлы удалены; `Gioui.UI_VERSION` указывает на `Script.VERSION`.
