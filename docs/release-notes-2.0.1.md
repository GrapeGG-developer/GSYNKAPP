# GSYNK 2.0.1

Небольшое, но важное обновление: включён канал обновлений по воздуху.

## Что нового

- **Репозиторий обновлений подставляется сам**: `GrapeGG-developer/GSYNKAPP`.
  Открывайте «Инструменты → Обновление GSYNK» и просто нажимайте «Проверить обновление».
- **Синтез речи** переведён на `Locale.forLanguageTag("ru-RU")` — компиляция без
  предупреждений, голос тот же.
- Документация: полное описание модулей, схема релизов и автосборка на GitHub.

## Как проверить обновление (по шагам)

1. Установите **2.0.0** (файл `GSYNK-v2.0.0-debug.apk` из этого репозитория).
2. Откройте GSYNK → **Инструменты → Обновление GSYNK**.
3. Нажмите **«Проверить обновление»** — приложение увидит 2.0.1.
4. Нажмите **«Скачать и установить»** — GSYNK скачает APK и откроет системный
   установщик. Android спросит разрешение на установку — разрешите.
5. После установки проверьте версию в «Настройки → О приложении»: 2.0.1.
