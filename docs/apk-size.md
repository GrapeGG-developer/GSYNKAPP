# Размер APK: из чего состоит сборка

Замеры на версии 2.1.0 (debug, Android SDK 36, build-tools 36.0.0).

## Обычная debug-сборка — 79 МБ (146 МБ до фильтра процессоров)

| Часть | Размер | Доля | Что внутри |
|---|---|---|---|
| `lib/` | 43.8 МБ | 55 % | нативные библиотеки MediaPipe для локальной модели (arm64-v8a 25.4 МБ, armeabi-v7a 18.3 МБ) |
| `dex` | 33.8 МБ | 43 % | код приложения + всего Compose/AndroidX/MediaPipe/zxing |
| `res` | 1.8 МБ | 2 % | иконки, шрифты Inter (5 начертаний ≈ 2 МБ), разметка |
| прочее | 0.1 МБ | <1 % | манифест, метаданные подписи |

До версии 2.1 APK весил 146 МБ: внутрь попадали ещё библиотеки для эмуляторов
(`x86`, `x86_64` — 60 МБ), которые на телефоне никогда не используются. В сборке
оставлены только процессоры телефонов:

```kotlin
ndk {
    abiFilters += listOf("arm64-v8a", "armeabi-v7a")
}
```

## Release-сборка

`isMinifyEnabled = false` — код не минифицируется, поэтому dex почти не отличается
от debug. Включение R8 ранее давало dex ≈ 2.5 МБ вместо 30 МБ (в 2.0.x),
то есть release-сборка была бы около 46 МБ.

Минификация выключена осознанно: приложение полностью офлайновое, размер не критичен,
а R8 требует отдельной проверки каждого рефлексивного вызова (DataStore, NFC, MediaPipe).

## Что даёт самый большой вклад

- **Локальная модель.** Библиотека MediaPipe `tasks-genai` тянет ~44 МБ нативных
  библиотек. Это плата за чат, который считает ответы прямо на телефоне.
  Сама модель (0.3–2.5 ГБ) в APK не входит — пользователь импортирует её файлом.
- **Наш код — 25 файлов, ≈9 500 строк Kotlin.** Остальное в dex — библиотеки
  Compose, AndroidX, Kotlin и MediaPipe.

## Итог

79 МБ за приложение с локальной ИИ, NFC-связкой, анимациями и мультитулом —
приемлемая цена; 55 % объёма занимает библиотека локальной модели, без неё
сборка была бы около 35 МБ.
