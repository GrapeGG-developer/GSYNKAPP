# GSYNK 4.0 «GSUI V4» — Metro, островок 2.0 и полный автопилот

Большое обновление оболочки: интерфейс переписан под язык **Metro (Windows 8.x / Windows
Phone)**, островок становится настоящим островком, обновления приходят сами, а внутри
появились ежедневный контент, 22 пасхалки, ИИ через настоящие API и почти три десятка
страниц лаборатории железа.

---

## 1. Связь: NFC стал честным

- **«Нет поддерживаемых приложений для метки» больше не выскакивает.** В манифест добавлен
  `nfc_tech_filter.xml` (NDEF, NDEF_FORMATABLE, NfcA/B/F/V, IsoDep, MifareClassic, MifareUltralight),
  а интент-фильтры получили мультиMIME, `text/plain` и схему `gsynk://`. Система больше
  не ищет «приложение для метки» — она отдаёт метку нам.
- **Одна правда о состоянии.** Раньше анимация рисовала «подключено» сама по себе, даже если
  рядом никого не было. Теперь единственный источник событий — `NfcPulse`: «жду касания»,
  «второй телефон читает», «метка прочитана», «записано на метку». Нет касания — нет зелёного.
- **Коннект стал полезным.** После чтения метки вторая сторона получает готовые действия:
  передать сцену, сценарий, сообщение, файл, обновление, сигнал «проверь обновление» —
  а не сообщение «подключено» без продолжения.

## 2. Вшитый отчёт об ошибках

Токен и репозиторий зашиты в приложение (`core/Keys.kt`, четыре части, чтобы сканер GitHub
не блокировал push). Пользователь больше ничего не вводит: отчёт уходит в `crash-reports/`
одним нажатием, секреты из текста вырезает санитайзер.

## 3. «Нагрузка» — полноценный стенд

- Семь этапов: целые числа, дроби, матрицы 128×128, память, накопитель, все ядра, ускоритель.
- Открытая формула балла, класс устройства (от «бюджетного» до «флагмана»), сравнение с
  прошлым прогоном («заметно медленнее — возможно, троттлинг») и «против телефона друга».
- История из 12 прогонов, передача результата одним текстом (меткой или сообщением).
- Плюс честная **нагрузка на телефон**: разогрев всех ядер с автостопом по 45 °C, чтобы не жечь.

## 4. Островок 2.0

- **Реально под фронтальной камерой**: позиция считается от выреза (`displayCutout`), а не от
  «примерно сотни пикселей сверху».
- Максимальное скругление, свои цвета для тёплого и холодного состояния, прогресс-полоса.
- **Обновления едут в островке**: скачивание APK показывается живым процентом, окно не
  пересоздаётся, финал — «скачано, ставлю» или «не скачалось» (и причина).
- Новая проверка версии тоже приходит капсулой с молнией — без всплывающих окон.

## 5. Обновления полностью автоматические

Ручная проверка убрана: круг автопроверки — 2 минуты, при возвращении в приложение — 90 секунд,
заметка о «несвежих» данных и скачивание APK прямо из островка. По-прежнему в пределах лимита
GitHub (30 запросов в час против 60).

## 6. Metro (Windows 8.x) в каждой детали

- Палитра Windows Phone 8 и Windows 8 (Cobalt, Indigo, Violet, Magenta, Crimson, Teal, Lime…).
- Типографика Segoe UI из четырёх размеров: 42 pt Light — заголовок, 20 pt Light — подзаголовок,
  11 pt Semilight — текст, 9 pt — подписи; строка заголовка — строчными с разрядкой.
- Контент с отступом в шесть единиц (20 px сетка), иконки приложения 48×48 без цвета,
  плитки трёх размеров (квадрат, широкий, большой) с зазором в одну единицу.
- Заголовки страниц больше не «жирные градиенты»: светлый тонкий шрифт, как в Windows 8.

## 7. Плитки и каталог

- Главный экран — **плитки Windows Phone 8–10**: квадратные, живые (счётчики, графики,
  переворот цифры), трёх размеров, без «под-под-подпунктов».
- **Каталог из 66 плиток** в семи категориях (связь, экран, железо, нагрузка, умное, система,
  забава) с поиском и шестью видами сортировки: часто, по алфавиту, недавние, категории,
  избранное, новое. Избранное и недавние хранятся на устройстве.
- Каждая плитка несёт своё скругление и свой цвет из палитры — «везде разное скругление»,
  как просили: плитки квадратные, переключатели средние, островок максимально круглый.

## 8. Эффекты: стекло, лучи, зерно, фокус

- Четыре вида стекла — матовое, жидкое, морозное, аква; размытие работает в реальном времени
  (на Android 12+), ниже — заменяется раскраской, чтобы не ронять кадры.
- Обрезка теней, лучи, зерно, фокус-кольцо, «вуаль» и сетка собираются в один стиль;
  фон переливается и реагирует на акцент из настроек.
- Три уровня эффектов: полные, облегчённые, простые. Слабому железу (вроде POCO X3 Pro)
  полный набор не выдаётся — включается автоматически по профилю устройства.

## 9. Лаборатория железа: 25 экранов и 24 дополнения

- Прежние: стробоскоп, мерцание (ШИМ), датчики, катушки, магнит, фонарик, ИК, музыка, тон,
  кодек, экран, калибровка и другие.
- Новые дополнения: ШИМ-микроскоп, компас, барометр и высота, гироскоп-уровень, запись
  акселерографа, датчик приближения, датчик света, заряд/ток/напряжение, термощуп по зонам,
  аудио-осциллограф, свип-генератор, ультразвук, мультитач-поле, магнитный след, BLE-карта,
  каналы Wi-Fi, сила сигнала Wi-Fi, USB/OTG, задержка экрана, вибро-код, счётчик шагов, ядра,
  память, ускоритель.
- На всех страницах железа — предупреждение о безопасности: загрузчик, прошивка и разделы
  не трогаются никогда.

## 10. Случайность и ежедневность

- **«Каждый день»** — новая порция: факт о железе, задание, прикол, число дня и цвет дня.
  Контент детерминирован по дате: у двух телефонов в один день набор одинаковый.
- Серия посещений и подарок за 3, 7, 14 и 30 дней подряд.
- **Рулетка** — «дай случайную функцию»: выбирает плитку из каталога и открывает её,
  редкие выпадают по-настоящему редко.
- **22 пасхалки**, каждая — реальное действие: три тире в морзянке, десять касаний NFC,
  960 Гц в мерцании, OTG-переходник, телефон лицом вниз, семь касаний значка, вертикальный
  телефон, 45 °C, 18 Гц катушки, давление ±5 гПа, 100 шагов, 90 дБ свистка, три стекла,
  «всё скруглённое», три прогона стенда и другие. Найденные видны в списке, ненайденные —
  с подсказкой; за находки открывается **секретный набор кожи** (аква-стекло, лучи, скругления).

## 11. ИИ по-настоящему

- Шесть вариантов: офлайн-помощник, OpenAI, Groq, OpenRouter, Ollama на своём компьютере,
  любой совместимый адрес. Настройки — адрес, модель, ключ, температура, длина ответа.
- Запросы идут напрямую из приложения (`/chat/completions`), есть проверка соединения,
  подсказки по каждому провайдеру и офлайн-режим без интернета.

## 12. Стабильность

- **200 тестов** (было 163): добавлены проверки стенда, пульса NFC, вшитых ключей, радара BLE,
  ИИ-сети и переворота телефона.
- 0 ошибок Lint. Починены `SocketException: Socket closed` при закрытии каналов связи —
  теперь чтение обёрнуто в безопасный вызов, а циклы проверяют живость корутины.
- Включён фильтр системных AON-датчиков: Android 16 больше не роняет процесс при обращении
  к «скрытым» датчикам.
