# GSYNK 5.9.0 EXP — GSYNK Blades

**versionCode:** 37 · **versionName:** 5.9.0 · **оболочка:** Xbox 360 Blade Dashboard

## Новый UI

- **«Пуск» полностью переработан в классические Blades:** горизонтальные вкладки-лезвия сверху, вертикальный список функций внутри выбранного лезвия.
- **Канонический стиль Xbox 360:** тёмно-зелёный/чёрный градиент, angled-панели, белые иконки, пульсирующая лаймовая рамка фокуса.
- GREAL-аврора, объёмные сферы, XMB-волны и бесконечные орбиты убраны из оболочки «Пуска».
- Общий фон приложений, карточки, кнопки, чипы, заголовки, разделители и шапка открытого окна переведены на Blade-стиль.
- Единое приложение настроек переименовано в **«Настройки Blade UI»**: живое превью лезвий, скорость светового пробега, яркость рамки, плотность панелей и глубина наклона.

## Навигация и управление

- Один общий `awaitEachGesture`-детектор с непрерывной фазой лезвий и пунктов.
- Инерция после отпускания, пружинное доведение `Animatable`, кратчайший циклический переход через край.
- Крупные экранные кнопки **← / → / ↑ / ↓ / OK**.
- Тап по соседнему пункту плавно наводит фокус; тап по фокусу или OK открывает приложение.
- Долгое нажатие по-прежнему закрепляет функцию в «моё».

## Архитектура

- `core/Blade.kt`: фаза, циклическое расстояние, ближайшая фаза, инерция, границы трансформов, световой пробег и палитра.
- `ui/BladeDesign.kt`: фон, лаймовая рамка, поверхности, кнопки и белые иконки без серых линий и кассетных кругов.
- `ui/BladeStartScreen.kt`: лезвия, список функций, непрерывный drag и экранные кнопки.
- `ui/BladeSettingsScreen.kt`: настройки Blade UI.
- Устаревшие `Xmb.kt`, `XmbDesign.kt`, `XmbStartScreen.kt`, `XmbDesignTest.kt` и `GrealSettingsScreen.kt` удалены из рабочего дерева.
- `Gioui.UI_VERSION` теперь указывает на `Blade.VERSION`.
