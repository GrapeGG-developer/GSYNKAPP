# GSYNK 5.1 — «запуск только горизонтально» (versionCode 23)

## Исправление

В GSYNK 5.0 пустой дом ошибочно требовал портретный режим и открывал «Пуск»
касанием. В 5.1 поведение полностью противоположное:

- телефон нужно повернуть **горизонтально**;
- в портретной ориентации виден только экран с требованием поворота;
- касание портретного экрана ничего не запускает;
- как только телефон становится горизонтальным, «Пуск» открывается **сам**,
  без лишних касаний;
- если после поворота открыта плитка или есть свёрнутая активная закладка,
  её состояние не сбрасывается;
- возврат в портрет снова показывает только экран требования.

## Альбомная сетка «Пуска»

Альбомный экран широкий и низкий, поэтому старая пятиколоночная сетка
пересобирается по доступной высоте. Группы плиток становятся шире и уходят
вправо внутри горизонтального «Пуска», вместо того чтобы обрезаться снизу.
Поворот не пересоздаёт Activity, поэтому Compose-состояние не теряется.
