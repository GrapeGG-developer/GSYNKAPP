# GSYNK 5.3.0 — «автообновление и чистый кэш» (versionCode 24)

## Что изменилось

### Веб-версия удалена, сайт загрузки остался

- Удалена веб-версия GSYNK (`app.html`) и её PWA-обвязка.
- Главная страница сайта сохранена: она по-прежнему сама спрашивает GitHub о
  последнем релизе и подставляет прямую ссылку на свежий Android APK.
- Старые ссылки «Открыть веб-версию» убраны с главной и страницы 404.

### Автообновление

- Внутренний сторож обновлений просыпается каждые **200 мс** и проверяет,
  наступил ли срок очередной проверки, не вернулся ли пользователь из
  системных настроек установки и не пора ли продолжить обновление.
- Сам HTTP/ETag-запрос к GitHub намеренно не делается пять раз в секунду: он
  идёт по расписанию (обычно раз в минуту, при ошибках и rate-limit — с
  отступом). Иначе телефон держал бы радио постоянно включённым, а GitHub
  быстро начал бы ограничивать обращения.
- Когда новая версия найдена и автообновление включено, GSYNK сам скачивает
  APK, проверяет SHA-256 и открывает системный установщик Android. Ручная
  кнопка в панели осталась запасным путём.
- Фоновая задача может заранее скачать APK по немобильной сети и показать
  уведомление «файл уже скачан». Полностью тихая установка обычному Android-
  приложению запрещена системой, поэтому последнее подтверждение «Установить»
  показывает сам Android.
- Отменённый установщик не выскакивает каждую минуту: повторная авто-попытка
  для того же тега ждёт 20 минут, а ручная кнопка работает сразу.

### Очистка старого APK

- Установщик скачивается только во внутренний кэш приложения как
  `gsynk-update.apk`.
- Сразу удалять его нельзя: файл нужен системному установщику. Поэтому при
  первом запуске уже новой версии GSYNK читает versionCode внутри скачанного
  APK, сравнивает его со своим и удаляет файл, если он уже установлен или
  старше текущей версии.
- Недокачанный `gsynk-update.part` помечается версией и ссылкой; чужие куски
  не продолжают загрузку другой версии и удаляются как мусор.
