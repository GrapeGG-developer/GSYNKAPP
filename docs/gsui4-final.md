# GSUI V4 — 14 пунктов, все закрыты

Итог по замыслу GSUI V4. Ниже каждый пункт замысла и где он живёт в коде — чтобы можно было
проверить, а не верить. Версия, которой это закрыто: **4.0.4 (versionCode 19)**.

## Что просили и что сделано

**1. NFC починить полностью** — `core/NfcPulse.kt`, `core/NfcReader.kt`, `core/NfcTagWriter.kt`,
`ui/NfcLinkScreen.kt`, `res/xml/nfc_tech_filter.xml`
Четыре MIME-типа, `text/plain`, схема `gsynk` и `TECH_DISCOVERED` с девятью технологиями;
сообщение метки из трёх записей, разбор предпочитает простые. Анимация подключения рисуется
только по настоящему касанию — единственный источник событий `NfcPulse`. После коннекта есть
чем заняться: сцена, правила, сообщение, файл, передача обновления, сигнал «проверь обновление».

**2. Больше функций в «GSYNK рядом»** — `ui/NearbyScreen.kt`, `core/Nearby.kt`
Bluetooth, Wi-Fi Direct и NFC в одном экране; в 4.0.4 добавлены задержка связи (`PING`/`PONG`),
отправка профиля телефона и своего заряда, визитка, своя точка на карте. Заряд друга виден
на экране связи.

**3. Токен и репозиторий вшиты** — `core/Keys.kt`
Четыре части ключа плюс `by lazy` и `Keys.REPO`. В тестах проверяется, что ключ не лежит
одной строкой. Санитайзер отчётов вырезает секреты.

**4. «Нагрузка» = аналог AnTuTu + чистая нагрузка** — `core/Bench.kt`, `ui/BenchScreen.kt`
Семь этапов, открытая формула балла, класс устройства, сравнение прогонов и с телефоном друга,
история 12 прогонов. Нагрузка — разогрев всех ядер с автостопом по 45 °C.

**5. Metro (Windows 8.x) и переработка интерфейса** — `ui/Metro.kt`, 27 файлов интерфейса
Сетка 20 px, зазоры в один юнит, размеры плиток 1×1 / 2×2 / 4×2, палитра Windows Phone 8 и
Windows 8, типографика Segoe UI. Раскладка `MetroGrid` без наложений, все экраны на `Metro.Type`.

**6. Больше плиток, без под-под-подпунктов, категории и сортировка** — `ui/Catalog.kt`
69 плиток, 7 категорий, 6 сортировок, поиск, избранное. У каждой плитки есть папка и экран —
сторожа `V4P1Test` и `CatalogGuards` держат это правило.

**7. Меню обновления полностью автоматическое, обнова приходит анимацией в островке** —
`core/UpdateChecker.kt`, `core/UpdateJobService.kt`, `ui/MainViewModel.kt`, `ui/UpdateSheet.kt`
Проверка раз в минуту с токеном и меткой ETag (ответ 304 лимит не тратит), три попытки,
запасной путь через страницу `releases/latest`. Панель выходит при находке и напоминает
каждые 20 минут, пока версию не установили. Фоновая задача на `JobScheduler` находит версию
даже с закрытым приложением, уведомление открывает панель. Скачивание: три попытки,
продолжение с места обрыва, проверка sha256.

**8. Островок 2.0 под фронтальной камерой, real-time фон** — `core/IslandService.kt`,
`core/IslandOverlay.kt`, `ui/Gsui4Screens.kt`, `ui/Effects.kt`
Посадка по вырезу камеры, максимальное скругление, живое стекло, смещение настройкой,
прогресс скачивания в реальном времени, финал «скачано, ставлю».

**9. Скругления точечно** — `core/Skin.kt`
Плитки квадратные, остров максимально скруглён, переключатели средне: у каждого элемента
своё скругление, «везде разное».

**10. Пасхалки, ежедневный контент, настоящие ИИ-API** — `core/Daily.kt`, `core/AiNet.kt`,
`ui/Gsui4Screens.kt`, `ui/AiScreen.kt`
Набор дня из даты, серия посещений, подарки на 3/7/14/30 дней, рулетка «случайная функция»,
22 пасхалки за реальные действия. ИИ: офлайн-помощник, OpenAI, Groq, OpenRouter, Ollama и
свой адрес — с проверкой соединения.

**11. Лаборатория железа сильно расширена** — `ui/LabScreen.kt`, `ui/DeviceLabA.kt`,
`ui/DeviceLabB.kt`, `core/ChipLab.kt`, `core/Deep.kt`, `core/Flicker.kt`, `core/BleRadar.kt`
25 экранов и 24 дополнения: ШИМ-микроскоп, мерцание камерой, компас, барометр, гироскоп-уровень,
акселерограф, приближение, люксметр, заряд и ток, термощуп по зонам, осциллограф, спектр,
свип-генератор, ультразвук, мультитач, магнитный след, BLE-карта, каналы Wi-Fi, USB/OTG,
задержка экрана, вибро-код, ядра, память, ускоритель. В 4.0.4 добавлены эхо-линейка и пульс
камерой. Везде `DeviceLab.SAFETY_NOTE`: загрузчик, прошивку и разделы не трогаем.

**12. Real-time эффекты** — `ui/Effects.kt`, `ui/Components.kt`
Матовое, жидкое, морозное и аква-стекло, живое размытие, лучи, трассировка тени, зерно,
фокус-кольцо, вуаль, сетка; уровни полные / облегчённые / простые по профилю железа.
`AuroraField` и `ParallaxBox` работают на всех экранах без потери функций и вида.

**13. Финальная стабильность и полировка** — 306 тестов, Lint 0
Сторожа: вложенная прокрутка, системные AON-датчики Android 16, целостность каталога, маршруты
без тупиков, вшитые ключи, формат чисел. Сбои ловятся в `core/AppLog.kt`, отчёты уходят
в `crash-reports/` через `core/ReportUploader.kt` с санитайзером.

**14. «Добавь многого от себя»** — что добавлено сверх списка
Связь с агентом прямо в приложении (`core/AgentMail.kt`, `ui/AgentMailScreen.kt`), проверка
зрения, эхо-линейка, пульс камерой, канал связи с задержкой и профилем, ежедневные подарки,
рулетка, папки вместо фильтров, 8 фаз чипа, капсула «агент ответил», фоновая проверка обновлений.

## Чем это проверено

- `bash check.sh` — сборка, **306 тестов**, Lint без ошибок, APK.
- Живые прогоны на телефоне: NFC-метка, обмен по связи, стенд, остров, обновление с GitHub.
- Проверки GitHub вживую: лимит с токеном 5000/час, ответ 304 не тратит лимит, запасной путь
  через `releases/latest` отдаёт тег.
