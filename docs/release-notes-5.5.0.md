# GSYNK 5.5.0 — «GSYNK-AI: свои ИИ-модели с ПК» (versionCode 28)

## Главное

- **Все старые встроенные ИИ удалены полностью**: сетевой «умный помощник» и крошечная нейросеть, управлявшая переливанием фона. Режим фона теперь выбирается честными правилами.
- **Отдельно оставлен командный ИИ** (GrapeBot): плитка «командный ии» понимает команды («яркость 40», «фонарик вкл») и работает офлайн.
- **Новая Windows-программа GSYNK-AI** создаёт и обучает настоящие нейросети-трансформеры с нуля на вашем ПК:
  - имя, иконка и размер модели — от mini (≈3 млн параметров) до max (≈45 млн);
  - датасет: свои диалоги `вопрос => ответ`, кнопка генерации русского датасета, статьи русской Википедии и текст любых страниц из интернета, а обученная модель может сама дописывать датасет;
  - обучение в режиме ТУРБО на 100% мощности ПК (видеокарта через DirectML или все потоки процессора), график loss, контрольные точки, продолжение после остановки;
  - как только жмёте «Хватит, стоп» — открывается проверка модели в чате программы; можно править датасет и учить дальше;
  - кнопка «Выпустить» отправляет модель на сервер GitHub;
  - сама программа обновляется прямо из себя.
- **Плитка «GSYNK-AI модели» в GSYNK** показывает каталог сервера, скачивает модели (с проверкой контрольной суммы) и запускает их прямо на телефоне — общение идёт на процессоре устройства, без интернета. Моделей может быть сколько угодно; пакет `.gsai` также можно импортировать вручную из файла.

## Первая модель

На сервере уже лежит демо-модель **«Виноградик»** 🍇, обученная ядром GSYNK-AI на сгенерированном русском датасете: болтает, считает простые примеры и рассказывает факты.

## Как скачать GSYNK-AI для Windows

Файл `GSYNK-AI.zip` — в релизе `gsynk-AI-v1.0.1`. Распакуйте и запустите `run.bat`
(нужен Python 3.10+; при первом запуске библиотеки поставятся сами), а `build_exe.bat`
соберёт один `GSYNK-AI.exe`.
