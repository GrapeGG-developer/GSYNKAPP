# GSYNK 2.3.1

Небольшое обновление: устранён вылет при нажатии NFC.

## Что было

По отчётам с телефона (два сбоя 13.10.2026, 19:24):

```
IllegalStateException: Vertically scrollable component was measured with an
infinity maximum height constraints, which is disallowed
```

Экран сопряжения Grape Link (открывается касанием NFC → «Открыть комнату»)
завёл **свою вертикальную прокрутку внутри `GrapeScreen`**, который уже
прокручивает содержимое. Compose такие вложения запрещает и останавливает
приложение — отсюда падение сразу при открытии сопряжения.

## Что исправлено

- Своя прокрутка убрана: содержимое сопряжения живёт внутри общей.
- Новый сторож **`ScrollGuardTest`** (3 теста) читает исходники интерфейса и не даст
  вернуть ни свою прокрутку внутри `GrapeScreen`, ни список без собственной высоты.
  Он же проверяет два законных случая (блок с ограниченной высотой и чат с явной
  высотой) — ложных срабатываний нет.
