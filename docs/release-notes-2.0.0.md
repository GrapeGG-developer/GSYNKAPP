# GSYNK 2.0.0 — «мультитул»

Первый большой релиз: GSYNK из планировщика яркости вырос в цельный мультитул.

## Новые модули

- **Постоянный остров** рядом с фронтальной камерой: часы, заряд батареи и ближайшее
  правило. Живёт постоянно, реагирует на нажатие пружинистой анимацией и раскрывает
  дополнительную строку. Три положения на экране.
- **Grape Link (NFC)** — связка двух телефонов касанием: приём в reader-режиме и
  передача через Host Card Emulation (телефон работает NFC-меткой), потому что
  Android Beam в Android 16 удалён. Успешное касание сопровождает анимация «жидкое стекло».
- **Мини-игры**: змейка, проверка реакции и дуэль по касанию — результат игры
  передаётся второму телефону вторым касанием.
- **Задачи**: через 1/3/10 минут позвонить контакту и произнести фразу синтезом речи;
  режим «Розыгрыш» — ложный входящий звонок плюс озвученная фраза.
- **Фонарик и «Не беспокоить»** — живые плитки-переключатели.
- **DVD-скринсейвер**: логотип летает и отскакивает, каждый отскок меняет оттенок.
- **GrapeBot** — локальный чат-помощник: «яркость 40», «громкость 0», «фонарик»,
  «не беспокоить», «включи автопилот», «сколько правил», «время».
- **Обновление по воздуху (OTA)** — проверка релизов GitHub, загрузка APK и установка.
- **MAIN-режим**: функции включаются по профилю устройства. Poco X8 Pro Max получает
  всё, старые телефоны (Poco X3 Pro, Android 13) — базовый набор: расписание,
  фонарик, NFC-обмен, мини-игры, скринсейвер. Режим переключается вручную.
- **Живые плитки в стиле Metro** вместо обычных кнопок: пружинистое нажатие,
  виброотдача, обновляемые подписи (обратный отсчёт до правила, рекорды, режим).
- **GRAPEUI** — каркас «ОС внутри приложения»: рабочий стол, плитки, часы.

## Исправления

- Состояние фонарика отслеживается системным колбэком (в Android 16 метода `getTorchMode` нет).
- Скринсейвер считает размеры по окну приложения — корректен в мультизадаче и на складных.
- Lint: 0 ошибок. Тестов стало 38 (было 22).

## Установка

Пакет `com.gsynk.app.debug`, минимальная версия — Android 11. Требуется разрешить
установку из неизвестных источников: это debug-сборка, подписанная debug-ключом.
