# GSYNK 2.1.1

Обновление 2.1.1 закрывает вылет при входе в «Инструменты», добавляет сбор отчётов
и делает интерфейс полностью острым — без единого закругления.

## Что исправлено

**Вылет при входе в «Инструменты».** Раздел читал показатели телефона незащищёнными
системными вызовами: на части прошивок такой запрос завершается ошибкой, и приложение
падало сразу при открытии. Теперь снимок состояния полностью защищён — при любой
ошибке подставляются безопасные значения, а сама причина уходит в журнал. Заодно
закрыты фонарик, режим тишины и цикл обновления дашборда: они больше не могут
прервать работу приложения.

## Отчёты и анализатор

- **Инструменты → Приложение → Диагностика.** Кнопка «Собрать отчёт», живой журнал,
  список отчётов, просмотр, копирование, отправка и удаление.
- **Отчёты о сбоях собираются сами.** Если приложение когда-либо упадёт, отчёт с
  описанием обстоятельств сохранится автоматически, а при следующем запуске появится
  баннер с быстрым переходом к разбору.
- **Анализатор сбоев.** Одинаковые падения считаются вместе: видно подпись
  («что сломалось и где»), сколько раз повторялось и когда было последним. Сверху —
  вывод, что чинить в первую очередь; разбор попадает и в сам отчёт.
- **Постоянный журнал.** Приложение ведёт журнал событий (правила, остров, NFC,
  инструменты, игры), поэтому разбор идёт по фактам, а не по догадкам.
- **Автоотправка по желанию.** Можно указать свой репозиторий GitHub и токен: отчёты
  уйдут в папку `crash-reports/`. Перед отправкой из отчёта вырезаются токены, почта
  и длинные числа. Пока автоотправка выключена, данные не покидают телефон.

## Острый интерфейс

Ни одного закругления во всём приложении:

- плитки, карточки, чипы, панели, шиты, диалоги, меню, подсказки и бейджи — прямые;
- переключатели перерисованы: собственный острый тумблер с квадратным бегунком;
- остров уведомлений тоже прямоугольный;
- логотип и анимации перерисованы без скруглённых форм.

## Проверки

50 модульных тестов (санитайзер отчётов и анализатор сбоев), Lint без ошибок,
сборка проверена на Android 36.

## Установка

Скачайте `GSYNK-v2.1.1-debug.apk` и установите поверх предыдущей версии — подпись
та же, данные и правила сохранятся.
