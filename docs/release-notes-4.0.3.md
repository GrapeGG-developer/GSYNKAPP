# GSYNK 4.0.3 — обновления приходят сами

Выпуск целиком про то, на что ты жаловался: «обновы неохотно приходят и панель обновления
не всегда показывается». Разобрал обе причины до конца и убрал их.

## Почему обновления приходили неохотно

- **Проверка шла без токена.** Без токена у GitHub лимит — 60 запросов в час **на адрес**.
  Телефон выходит в сеть через общий адрес оператора, поэтому запросы отбивались кодом
  `403`, и приложение просто не узнавало о новых версиях. Теперь проверка идёт с вшитым
  токеном: лимит **5000** обращений в час.
- **Ответы по метке ETag.** Если версия не изменилась, GitHub отвечает `304`, и такой ответ
  **не тратит лимит вообще**. Поэтому проверку можно делать раз в минуту — стало быстро
  и почти бесплатно.
- **Три попытки вместо одной** и внятная причина ошибки (лимит, сеть, ответ сервера)
  прямо в панели, а не молчание.
- **Запасной путь.** Если API почему-то закрыт, версия всё равно определяется по странице
  `releases/latest` — приложение показывает, что есть что-то новое, и открывает страницу релиза.

## Почему панель показывалась не всегда

- Раньше панель открывалась только на «изменение флага»: закрыл её один раз — и всё,
  больше она не появится. Теперь модель **командует показом**: панель выходит при находке
  версии и напоминает каждые 20 минут, пока ты её не установил или не пропустил.
- Закрытие панели больше **не считается отказом**.
- Два разных действия вместо одного:
  - **«Напомнить позже»** — панель вернётся через 10 минут;
  - **«Пропустить версию»** — об этой версии больше не напоминаю (можно вернуть кнопкой
    «Вернуть напоминания»).
- Капсула в островке напоминает раз в 15 минут, а не один раз за всё время.

## Обновление находит телефон, даже когда приложение закрыто

- Добавлена **фоновая проверка** на встроенном в Android `JobScheduler` — без лишних
  библиотек. Будит приложение раз в полчаса, только при наличии сети, переживает
  перезагрузку телефона.
- Нашла новую версию — показывает уведомление. **Нажатие открывает приложение сразу
  на панели обновления.**
- Выключишь автопроверку в настройках — фоновая задача снимается вместе с ней.

## Скачивание стало упрямым

- Три попытки, продолжение с места обрыва (заголовок `Range`), проверка, что скачался
  действительно APK, и сверка `sha256` с тем, что сообщил GitHub.
- Если ссылки на APK нет (версия видна только на странице релиза) — сразу открывается страница.

## Что видно на экране обновления

- Строка состояния проверки: «проверяю версию…», «версия в порядке», «лимит обращений не потрачен».
- При неудаче — честная причина, пояснение про лимит GitHub и кнопки «Повторить» / «Страница релиза».
- Подпись внизу: «Раз в минуту, с токеном и меткой ETag — лимит GitHub не тратится».

## Проверки

- **267 автотестов**, 0 падений. Отдельные проверки: разбор ответа GitHub, сравнение версий,
  политика напоминаний, задержки при ошибках, фоновая задача, «уведомление один раз на версию»,
  открытие панели по нажатию, сверка `sha256`.
- **Lint**: 0 ошибок.
- Обновление **ставится поверх** любой предыдущей версии — подпись та же.
