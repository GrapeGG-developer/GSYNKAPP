# GSYNK 5.0.0 — GIOUI и «Шифраторы»

Глобальное обновление. Старый интерфейс (GSUI/Metro) убран полностью и заменён на
**GIOUI — GSYNK INTELLIGENT OUR UI**: одна дизайн-система на всё приложение, функции
расфасованы по категориям, никаких старых файлах и огрызков. Плюс новая категория —
**«Шифраторы»**.

## GIOUI: единый новый UI

- **Одна дизайн-система `ui/Gioui.kt`** вместо удалённой `Metro.kt`: единый язык форм
  (карточки 24 dp, контролы 16 dp, листы 28 dp, чипы и островок — капсулы), своя
  виноградная палитра, компактная типографика. Материальная тема (шрифт Inter,
  формы, цвета) приведена к той же системе — все экраны звучат одним голосом.
- **Главный экран перестроен**: поиск по всем функциям сверху (результат сразу, без
  лишних экранов), карточка быстрых переключателей (автопилот, остров, уведомления),
  дальше — **категории**: связь, экран, железо, нагрузка, умное, **шифраторы**,
  система, забава. Каждая из 83 функций живёт ровно в одной категории; ниже — расписание правил.
- **Нет старых остатков**: исходники и тесты переименованы (страницы — `GiouiScreens`,
  дизайн — `Gioui`), удалены мёртвые компоненты ленты папок, радиусы 4.x не воскресают
  при обновлении — формы GIOUI читаются из новых ключей, а пресеты стали «GIOUI единое /
  строгое / мягкое / аква / облегчённое / компактное». Экран «Скругления» теперь настраивает
  значения вокруг канона GIOUI, а не возвращает квадратное прошлое.
- Функции при этом не потеряны: правила, остров, Grape Link, лаборатория, стенды,
  эхо-линейка, пульс, глаза, ИИ, связь с агентом и обновления — все на месте, в новом виде.

## Шифраторы (новая категория)

Один универсальный экран на все шифры: режим «зашифровать / расшифровать», одно поле
ввода, выбор шифра чипами по семьям — и **автоопределение**. Вставил чужой шифр —
приложение само называет его и предлагает расшифровать именно им (каждая догадка
проверяется настоящим декодированием в читаемый текст).

**Популярные (6):** Base64, HEX, URL-кодировка, азбука Морзе, Цезарь +7 (русский и
английский), XOR по ключевой фразе.

**Символы (8, по списку заказчика):** двоичный код; цифры **6 и 7**; цифры **4 и 2**;
буквы **G и S**; **только буква G** (G — ноль, GG — единица); **натуральные 1–9 без
нуля** (байт тремя цифрами); эмодзи 😡 и 😏; **виноград и банан** (виноград — единица).

**Уникальные GSYNK (4):** компактный **GSYNK-32** со своим алфавитом; плотный
**GS-85** (4 байта в 5 символов); красивая **«Виноградная лоза»** (каждые полбайта —
виноградное слово); строгий и тяжёлый **«GS-Замок»** — AES-256-GCM, ключ из пароля
прогоняется через PBKDF2 на 120 000 кругов — процессор телефона реально работает.

Честность как обычно: кодировки прячут текст только от случайных глаз, настоящую
секретность даёт «GS-Замок»; пароль нигде не хранится, в сеть ничего не уходит.
Всё считается локально и одинаково работает на любом Android 11+, включая Poco X3 Pro.
Результат можно скопировать, отправить или одним нажатием вернуть во ввод для обратной операции.

## Проверено

- **321 автотест** (включая новый `CipherTest`: круговые прогоны всех 18 шифров на
  русском тексте, чистоту алфавитов, автоопределение каждого шифра, отказы на битых
  данных, неверный пароль и подмену символа в замке), Lint — 0 ошибок.
- APK ставится поверх прошлой версии (подпись та же); интерфейс при обновлении сразу
  новый, старые радиусы не применяются.
