# GSYNK 2.3.0

Крупное обновление: лаборатория железа, обновления сами вылезают на экран, Grape Link
стал одним экраном, игра — одним сетевым режимом, а Gemma и импорт модели убраны.

## Обновления

- Проверка раз в **20 минут** (было раз в 6 часов) и при каждом возвращении в приложение.
- Новая версия **сама открывает панель обновления и закрывает все прочие панели**.
  Только живой бой не перебивается — там баннер дождётся.

## Интерфейс

- На экране всегда **ровно одна панель**: девять независимых флагов схлопнуты в один
  переключатель, поэтому окна больше не накладываются друг на друга.
- Жёсткий порядок слоёв: главный экран → панели → панель разрешений → показ по касанию →
  обновление. Панель разрешений раньше рисовалась под списком и перекрывалась контентом.
- Градиент фона больше не рваный: 24 секунды на цикл с мягкой кривой, широкая волна
  переливания и один общий акцентный оттенок на кадр.
- Нажатие на логотип GSYNK рассыпает виноградную гроздь.

## Grape Link: один экран, четыре плитки

- Один переключатель роли и плитки **GTBOI / Файл / Сценарий / Метка** вместо трёх вкладок
  и десятка кнопок-дублёров.
- **Передача файлов** по касанию: реквизиты уезжают в метке, файл едет по Wi-Fi, крошечные
  файлы — прямо в метке; принятое падает в «Загрузки/GSYNK».
- **Показ по касанию**: салют, сердечки, вспышка, надпись — и команды второму телефону
  (фонарик, вибрация, сирена).
- **Новое: запись на обычные NFC-метки** — GSYNK размечивает пустую наклейку и пишет на неё
  данные или сценарий.

## Игра: один режим

- Только GTBOI (подземелье в духе The Binding of Isaac) с другом **на двух телефонах**:
  касание NFC открывает комнату, подключает гостя и запускает игру само.
- Полноэкранный бой: приглушённое поле, стики поверх, прозрачные кнопки «пауза / заново / выйти».

## GrapeBot без модели

- Gemma, загрузка `.task` и зависимость MediaPipe удалены: APK похудел с 84 МБ до **35 МБ**.
- Остался помощник на командах: «яркость 40», «фонарик вкл», «открой статистику батареи»,
  «позвони 89001234567», «найди мурзик» — мгновенно и полностью офлайн.

## Лаборатория железа

| Инструмент | Что делает |
|---|---|
| Стробоскоп | мигание экраном 2–25 Гц, четыре палитры |
| Фонарик-строб | вспышка камеры 1–8 Гц |
| Экран | битые пиксели, выгорание AMOLED, очистка пикселей, градиент, ШИМ, мультитач, остаточный след |
| AMOLED-затемнение | гасит экран ниже системного минимума (и бережёт батарею) |
| Датчики | все датчики живьём + компас, уровень, высота по барометру |
| Катушки | вибромотор как катушка: 6 шаблонов и ритм 2–16 ударов/с; динамик: тон 60 Гц–17 кГц и развёртка 20 Гц→20 кГц |
| Индукция | металлоискатель на датчике Холла, проверка катушек вибро и зарядки |
| ИК-пульт | настоящий пульт (NEC) там, где есть излучатель — Poco X3 Pro и другие Xiaomi |
| Скрытое Android | 10 спрятанных системных экранов |
| HyperOS | автозапуск, контроль активности, Game Turbo, второе пространство, телеметрия и др. |
| Инженерные коды | *#*#6484#*#*, *#*#4636#*#* и другие — одной кнопкой |

Ничего опасного: загрузчик, прошивка и разделы Android не трогаются. Это написано на
экране лаборатории.

## Старым телефонам — больше возможностей

- Новый уровень **«расширенный набор»** для Poco X3 Pro и подобных: лаборатория, датчики,
  индукция, ИК-пульт, разделы HyperOS — да; флагманская максимальная нагрузка — нет.
- Карточка устройства показывает модель, экран, Android, уровень, ИК-порт, NFC и HyperOS.
