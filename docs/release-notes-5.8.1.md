# GSYNK 5.8.1 EXP — GREAL XMB Motion

**versionCode:** 36 · **versionName:** 5.8.1 · **тип:** хотфикс навигации XMB

## Что исправлено

- Убраны конфликтующие горизонтальный и вертикальный `detect*DragGestures`, из-за которых прокрутка дёргалась и перескакивала.
- Теперь один общий `awaitEachGesture`-детектор ведёт **непрерывную фазу** категорий и пунктов прямо под пальцем.
- Добавлена **инерция**: после отпускания скорость жеста переводится в дополнительные целые шаги, а `Animatable` пружинно доводит ряд до ближайшего индекса.
- Переход через край списка идёт по **кратчайшему циклическому пути**, без длинной прокрутки через все категории или пункты.
- Элементы считают плавное `Float`-расстояние до фокуса: масштаб, прозрачность, наклон и смещение меняются непрерывно, а не дискретно.
- Тап по соседнему пункту сначала плавно наводит фокус; тап по фокусу или кнопка «открыть» запускает приложение.
- Подсказка категории меняется через `AnimatedContent`, волна GREAL усиливается во время drag через `animateFloatAsState`.

## Удобное управление

- Добавлены крупные экранные кнопки **← / → / ↑ / ↓** и **«открыть»**.
- Кнопки дублируют жесты и работают той же инерционной анимацией, что и свайп.
- Сохранены касание категории, долгое нажатие для «моё», вибро/звуковой отклик и жидкое открытие окна из реальных координат плитки.
- В «Настройках GREAL UI» добавлена регулировка **инерции жестов XMB**; раздел переименован в «XMB Motion».

## Архитектура

- `core/Xmb.kt`: `normalizePhase`, `cyclicDistance`, `nearestPhase`, `flingSteps`, `settleTarget` и Float-перегрузки трансформов.
- `ui/XmbStartScreen.kt`: один общий pointerInput, `Animatable` для фазы категорий и фазы пунктов, циклические ряды без `LazyRow`/`LazyColumn`.
- `ui/XmbDesign.kt`: анимируемый параметр `motion` для волнового фона.
- `XmbDesignTest`: покрытие циклического расстояния, кратчайшего пути, инерции, границ анимации и отсутствия старых детекторов.
